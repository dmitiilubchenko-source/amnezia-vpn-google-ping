# AmneziaVPN Google Ping & Rank v3

Локальная сборка AmneziaVPN 5.0.3.0 для Windows / Premium: последовательная проверка доступных стран и сортировка по средней задержке до Google.

## Запуск

1. Завершите старую AmneziaVPN через значок в трее → «Выход / Quit». Крестик может только скрыть окно. Новая копия не сможет запуститься, пока работает старая; теперь об этом появляется сообщение.
2. У друга сначала должна быть установлена официальная AmneziaVPN 5.0.3.0 с рабочей службой Windows и его собственной подпиской Premium. Распакуйте весь ZIP сборки в отдельную папку и запустите AmneziaVPN.exe. На компьютере автора есть ярлык «Amnezia — Google Ping». Оставьте EXE вместе со всеми библиотеками.
3. Выберите свою подписку Premium как основную. Откройте её список стран: заголовок должен быть **Google Ping & Rank**, ниже указано **v3**.
4. Выключите раздельное туннелирование приложений для этой проверки. При раздельном туннелировании сайтов адрес Google должен идти через VPN.
5. Нажмите «Проверить все · Google» и подтвердите переподключения. После проверки страны с ответами будут сверху, от меньшего среднего ping к большему; рядом указаны потери и использованный протокол. Страны без результата остаются внизу с причиной.

VPN будет отключаться и подключаться для каждой страны. Интернет и этот чат могут временно потерять связь. По завершении или остановке программа пытается вернуть исходную страну, протокол и состояние подключения. При ошибке восстановления или капче потребуется подключиться вручную; причина будет показана на странице. Во время восстановления кнопка остановки не прерывает возврат подключения. Оставьте страницу проверки открытой: уход с неё останавливает проверку с возвратом к исходной стране.

Кнопка «Измерить текущую · Google» проверяет уже подключённую страну без переключений. Результаты хранятся в памяти до закрытия клиента. Повторная полная проверка обновляет все результаты.

Настройки общие с установленной AmneziaVPN. Сборка не подписана сертификатом Amnezia; автообновление отключено. Для возврата завершите её через трей и запустите прежний клиент. Переустановка службы для этого запуска не выполнялась.

## Метод измерения

`ping google.com -t` бесконечно проверяет Google через текущий маршрут. Команда сама не выбирает страны VPN и не сортирует их. В этой сборке Google определяется один раз перед полной проверкой: все страны проверяются на **одном IPv4-адресе**, чтобы смена DNS-ответа не подменяла цель.

Для каждой страны приложение получает конфигурацию через штатный Premium API, подключает VPN, ждёт готовности маршрута и выполняет 5 ICMP-запросов с данными 32 байта. Тайм-аут каждого запроса — 1 секунда. Показывается среднее RTT успешных ответов Windows ICMP API и процент потерь. Сначала сортируется среднее RTT, при равенстве — потери. Отсутствие ответа не превращается в 0 мс.

Исходный IPv4-адрес привязан к активному интерфейсу `AmneziaVPN`; маршрут Windows проверяется до и после запросов. Если не удалось подтвердить маршрут через VPN, показывается ошибка. Проверка приложений с раздельным туннелированием запрещена. Физический интерфейс не используется как запасной.

Это задержка **до Google через выбранную страну**, а не только до входного адреса VPN, не скорость скачивания и не ping конкретной игры. Блокировка ICMP в каком-либо туннеле означает отсутствие измерения; такая страна может при этом нормально открывать сайты. Некоторые страны могут требовать другой поддерживаемый протокол; он указан в результате.

## Проверки сборки

Клиент и служба собираются MSVC 2022 / Qt 6.10.0. Автотесты проверяют сортировку, единую цель, отказ отдельной страны, остановку с незавершённым API-запросом, игнорирование устаревших ответов и восстановление исходного состояния. Эти сценарии используют подставное сетевое окружение и не меняют пользовательский VPN.

Тот же ICMP-модуль проверен на действующем туннеле без переподключений: 5 из 5 ответов, среднее 86 мс. Одновременный Windows `ping` к тому же адресу также показал среднее 86 мс. Это один замер, не постоянная характеристика страны. Полный перебор реальной подписки при разработке не запускался, чтобы не прерывать соединение пользователя. `preview.png` содержит демонстрационные значения.

Исходники: официальный тег 5.0.3.0, commit de93650, ветка `codex/premium-latency`. Патч включает предыдущие диагностические модули ICMP/HTTPS, однако страница стран использует Google Ping & Rank. Зависимости закреплены в `conan.lock`.
