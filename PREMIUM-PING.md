# AmneziaVPN Google Ping & Rank v5

Локальная сборка AmneziaVPN 5.0.3.0 для Windows / Premium: проверка доступных стран в два этапа с учётом потерь, задержки и её стабильности.

## Запуск

1. Завершите старую AmneziaVPN через значок в трее → «Выход / Quit». Крестик может только скрыть окно. Новая копия не сможет запуститься, пока работает старая; теперь об этом появляется сообщение.
2. У друга сначала должна быть установлена официальная AmneziaVPN 5.0.3.0 с рабочей службой Windows и его собственной подпиской Premium. Распакуйте весь ZIP сборки в отдельную папку и запустите AmneziaVPN.exe. На компьютере автора есть ярлык «Amnezia — Google Ping». Оставьте EXE вместе со всеми библиотеками.
3. Выберите свою подписку Premium как основную. Откройте её список стран: заголовок должен быть **Google Ping & Rank**, ниже указано **v5**. Папка новой сборки — `AmneziaVPN-Google-Ping-v5-5.0.3.0`.
4. Выключите раздельное туннелирование приложений для этой проверки. При раздельном туннелировании сайтов адрес Google должен идти через VPN.
5. Нажмите «Проверить все · Google» и подтвердите переподключения. Первый этап — 5 измерений для каждой страны. Второй — 30 измерений с интервалом в секунду для пяти лучших стран с ответами (либо меньшего числа, если ответило меньше пяти). Второй этап занимает примерно полминуты на страну плюс подключение. Страны без ответа остаются внизу с причиной.

VPN будет отключаться и подключаться для каждой страны. Интернет и этот чат могут временно потерять связь. По завершении или остановке программа пытается вернуть исходную страну, протокол и состояние подключения. При ошибке восстановления или капче потребуется подключиться вручную; причина будет показана на странице. Во время восстановления кнопка остановки не прерывает возврат подключения. Оставьте страницу проверки открытой: уход с неё останавливает проверку с возвратом к исходной стране.

Кнопка «Текущая · 30» подробно проверяет уже подключённую страну без переключений. Кнопка со стрелками возле страны запускает 30 запросов только для неё; для уже подключённой страны переключение не требуется. В остальных случаях программа запрашивает подтверждение переподключения и в конце пытается вернуть исходное подключение.

Звёздочки добавляют страны в избранное. «Только избранные» фильтрует список, а «Избранные» проверяет только отмеченные страны — по 30 запросов без предварительного быстрого этапа. Во время проверки показаны прогресс и приблизительное оставшееся время с учётом переподключений; при затянувшемся подключении оценка времени скрывается.

Последний результат каждой страны и избранное сохраняются локально в зашифрованных настройках, отдельно для каждой подписки. У каждого замера есть дата; после перезапуска он помечен как сохранённый, спустя 24 часа — как устаревший. Новая проверка отображается выше прежних замеров, чтобы результаты разных запусков не выдавались за одновременное сравнение. Удаление подписки удаляет и её сохранённые результаты. История всех запусков не ведётся.

Над списком показывается лучшая страна **в последней проверке**, если есть свежий подробный результат с минимум тремя ответами из 30 запросов. Это может быть проверка только избранных или одной страны. Сохранённый лидер явно отмечен; при смене сети его следует перепроверить. Автоматическое переключение на лидера не выполняется.

Сначала показываются успешные **подробные** результаты, затем **быстрые оценки**. Внутри каждой группы порядок такой: меньше наблюдаемых потерь, затем меньше P95, медиана и разброс. Это прозрачный порядок сравнения, без условного «балла качества». Если уточнение страны не удалось, она отмечается ошибкой; прежние 5 ответов не выдаются за успешную подробную проверку.

Настройки общие с установленной AmneziaVPN. Сборка не подписана сертификатом Amnezia; автообновление отключено. Для возврата завершите её через трей и запустите прежний клиент. Переустановка службы для этого запуска не выполнялась.

## Ключи и профили

В опубликованных исходниках и Windows-архивах нет личного ключа Premium или профиля автора. Другу нужна собственная подписка: на чистом профиле необходимо импортировать свой ключ. Если AmneziaVPN уже настроена на его компьютере, сборка использует его существующий локальный профиль. Подписка из чужого компьютера вместе с EXE не переносится.

`tools/gateway-public.pem` — общий публичный ключ шифрования запросов к штатному API, а не личный ключ подписки. Сохранённые результаты содержат только страны, протокол, дату и итоговые метрики; ключи VPN, пароли, локальный IP и сырые пакеты в этот кэш не записываются.

## Метод измерения

`ping google.com -t` бесконечно проверяет Google через текущий маршрут. Команда сама не выбирает страны VPN и не сортирует их. В этой сборке Google определяется один раз перед полной проверкой: все страны проверяются на **одном IPv4-адресе**, чтобы смена DNS-ответа не подменяла цель.

Для каждой страны приложение получает конфигурацию через штатный Premium API, подключает VPN, ждёт готовности маршрута и выполняет один прогревочный ICMP-запрос, который не входит в результат. Далее идут 5 или 30 измеряемых запросов с данными 32 байта. Тайм-аут каждого — 1 секунда. Интервал между началами запросов: 200 мс на первом этапе и 1 секунда на подробном. Ответы с большей задержкой учитываются как пропущенные по этому тайм-ауту.

- **Медиана** — обычная задержка: середина отсортированных успешных RTT, для чётного числа — среднее двух центральных.
- **P95** — задержка, не превышенная как минимум 95% успешных ответов этой выборки; используется метод nearest rank. Потери учитываются отдельно.
- **Разброс RTT** — среднее абсолютное изменение RTT между соседними успешными запросами в исходном порядке. Через пропуск пары не соединяются. Это показатель изменения двусторонней задержки, не RTP jitter и не односторонняя метрика IPDV.
- **Потери** — доля запросов без успешного ICMP-ответа за 1 секунду, рядом показано число полученных/отправленных. Если соседних успешных ответов нет, разброс отображается как «—», а не 0.

Каждый подробный результат заменяет быстрый; выборки разных длительностей не смешиваются. Протокол подробного этапа берётся из быстрой проверки той же страны, если он по-прежнему доступен. При ручной смене страны или протокола во время измерения проверка останавливается. Отсутствие ответа не превращается в 0 мс.

Исходный IPv4-адрес привязан к активному интерфейсу `AmneziaVPN`; маршрут Windows проверяется до и после запросов. Если не удалось подтвердить маршрут через VPN, показывается ошибка. Проверка приложений с раздельным туннелированием запрещена. Физический интерфейс не используется как запасной.

Это задержка **до одного адреса Google через выбранную страну**, а не только до входного адреса VPN, не скорость скачивания и не ping конкретной игры. Блокировка ICMP в каком-либо туннеле означает отсутствие измерения; такая страна может при этом нормально открывать сайты. Некоторые страны могут требовать другой поддерживаемый протокол; он указан в результате. Для игры дополнительно смотрите статистику соединения внутри самой игры.

Подробный этап уточняет только предварительно выбранные пять стран. Выборка 30 запросов не гарантирует отсутствие будущих потерь или скачков: 0 из 30 пропусков означает только отсутствие пропусков в этом тесте. Результаты зависят от времени проверки и маршрута. Обзор различий метрик вариации задержки: [RFC 5481](https://www.rfc-editor.org/rfc/rfc5481).

## Проверки сборки

Клиент и служба собираются MSVC 2022 / Qt 6.10.0. Автотесты проверяют сортировку, единую цель, отказ отдельной страны, остановку с незавершённым API-запросом, игнорирование устаревших ответов и восстановление исходного состояния. Эти сценарии используют подставное сетевое окружение и не меняют пользовательский VPN.

В v3 ICMP-модуль и одновременный Windows ping на действующем туннеле показали среднее 86 мс. В v4 добавлены тесты медианы, P95, дробных потерь, разброса с пропусками и выбора пяти стран для уточнения. В v5 проверяются сохранение и изоляция результатов между подписками, избранное, повторная проверка одной страны, устаревание, прогресс и отсутствие встроенной подписки на пустом профиле. Полный перебор реальной подписки при разработке не запускался, чтобы не прерывать соединение пользователя. `live-test.json` и `windows-ping.txt` — сохранённая проверка неизменённого ICMP-модуля из v4 (среднее 108,5 и 107 мс соответственно), а не новая проверка v5. `preview.png` содержит демонстрационные значения.

Исходники: официальный тег 5.0.3.0, commit de93650, ветка `codex/premium-latency`. Патч включает предыдущие диагностические модули ICMP/HTTPS, однако страница стран использует Google Ping & Rank. Зависимости закреплены в `conan.lock`.
